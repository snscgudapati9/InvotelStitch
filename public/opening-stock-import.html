Opening Stock Import

Upload current physical stock, validate against Item Master, preview, then confirm posting.
Important: This creates opening stock batches and stock movements through a posted Goods Receipt. It does not modify Item Master records. Enter quantities in the exact Item Master unit and cost per that unit, including tax. Posting changes live stock and cannot be undone from this screen.

1 · Prepare your Excel file

Use the exact headers in the template. Match each row by Item Code or exact Item Name. Quantity, unit and unit cost are required. Cost must be the actual landed cost per listed unit; use 0 only when the actual cost is zero.

2 · Validation preview

Posting is enabled only when every row passes validation and at least one row is present.
